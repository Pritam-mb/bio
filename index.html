Publications & Research

Peer-reviewed work I've co-authored.

OmniML: A Multi-Agent LLM Framework for Human-in-the-Loop AutoML
Srijeet Prasad Banerjee, Pritam Patra (Co-Author), Ayushman Mukherjee, Tridib Chakraborty, et al.
  • Co-authored and developed an autonomous, end-to-end AutoML pipeline built with a LangGraph-based Directed Acyclic Graph (DAG) orchestrating 13 specialized LLM agents across the full ML lifecycle.
  • Designed a novel LLM-to-architecture compilation engine that translates natural-language problem constraints into typed React Flow JSON graphs, automatically compiled into valid PyTorch models via topological sort chains.
